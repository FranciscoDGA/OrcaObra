# OrçaObra

Orçamento e gestão de obras para pedreiros e mestres de obra.

## Funcionalidades

- **Orçamento rápido** — Descreva a obra em texto livre e o app interpreta as medidas
- **Orçamento por serviço** — Escolha a categoria, serviço e informe as medidas
- **Motor de precificação** — Calcula custo de mão de obra, despesas, reserva de risco e margens
- **Propostas para clientes** — Gere propostas profissionais sem expor custos internos
- **Gestão de obras** — Acompanhe progresso e gastos de obras aprovadas
- **Cadastro de clientes e materiais** — Reutilize dados em múltiplos orçamentos
- **PWA** — Funciona offline, instalável no celular

## Stack

- React 19 + TypeScript
- Tailwind CSS v4
- Zustand (state management)
- React Router v7
- Vite (build tool)
- Lucide React (ícones)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

npm run build
